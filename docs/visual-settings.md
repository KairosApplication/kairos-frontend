# Configurações — cobertura visual

Referência: captura Web (new), frame `574:2149`. Rota protegida `/configuracoes`.

Menu lateral com navegação por seções, dados da loja, idioma disponível em Português (Brasil), seleção ilustrativa de fuso, prévia local de tema claro/escuro, switches de alertas/resumo e cartão de sessões protegidas. O tema escuro se aplica somente à prévia desta página; não altera Sidebar, Header ou configurações globais.

Salvar altera somente o estado local e informa que a loja real não foi modificada. Gerenciar acessos apresenta sessões fictícias; encerrar exemplo remove somente o item da prévia, sem consultar ou revogar sessão real. A política de 30 minutos é um texto ilustrativo, não uma configuração aplicada no servidor. Recarregar ou sair restaura os exemplos. Nenhum e-mail é enviado.

PR independente criada da main `077293d`, com dados tipados e fonte temporária separada. DemoToggle é idêntico ao da PR de Perfil. Não há novos endpoints, persistência ou merge de outras telas.
